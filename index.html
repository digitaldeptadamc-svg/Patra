Department of Dravyaguna
Patra
Botanical Name :

  • Cinnamomum tamala T.Nees & Eberm.

    • Family Name :

  • Tejpat

    • Local Name :

  • Tamalapatra

    • Vernacular Name :

  • Hindi – Tejpat

  • English – Indian Bay Leaf

    • Synonyms :

  • Tamalapatra

  • Tejapatra


    • Habitat :

  • Found mainly in the Himalayan region of India, Nepal, Bhutan, and surrounding areas. It grows in cool, moist mountainous regions.


    • External Morphology :

  • Leaves: Simple, alternate, leathery, lanceolate to elliptic, aromatic, with three prominent veins.

  • Stem: Medium-sized evergreen tree with aromatic bark.

  • Flowers: Small, pale yellow-green, arranged in clusters.


    • Useful Parts :

  • Leaves


    • RasadiPanchaka :

  • Rasa – Tikta, Katu

  • Guna – Laghu, Ruksha

  • Vipaka - Katu

  • Virya - Ushna


    • Pharmalogical Action :

  • Vatanulomana

  • Krimighna

  • Shothahara


    • Therapeutic Administration:

  • Agnimandya: Leaf powder is traditionally used to improve digestion.

  • Ajeerna: Leaf preparations are traditionally administered.


    • Dose

  • Patra Churna: 1–3 g

  • Kwatha: 50–100 ml

  • Phanta: 50–100 ml


    • Formulation:

  • Panchakola Churna

  • Chaturbija Churna
